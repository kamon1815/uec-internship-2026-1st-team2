# uec-internship-2026-1st-team2
## 必要なツール
- mediapipeをインストールしてください
```python
pip install mediapipe
```
- numpyをインストールしてください
```python
pip install numpy
```
- mediapipe tasksのモデルをダウンロードしてください  
  mediapipe_sample内のdownload-requirements.pyを実行することでモデルをダウンロードできます。  


## voiceフォルダーについて
以下のサイトからダウンロードしました。

- サイト名:声と音の小部屋 酉月（こえとおとのこべや　ゆうげつ）
- 作曲者・作成者:古勝ともはる（こかつともはる）、旧名義：酉月ともはる
